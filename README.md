<a id="schnellstart"></a>
## 🚀 Start in one minute

1. Download the complete pack above, extract it, and open `index.html`.
2. Choose a path from the dashboard: use a helper, explore Launchpad, browse prompts, or open the Creator Kit.
3. Make one small change, keep the files, and build from there.

Opening the files directly works in most browsers. For a consistent local origin—especially if browser storage behaves differently with `file://`—run:

```sh
python -m http.server 8080
```

Then open <http://localhost:8080>. No build step is needed to use the pack.

## 🌙 Design principles

- **Small and finishable:** one obvious job per tool, with a useful starting point rather than an oversized interface.
- **Local-first:** no sign-in, cloud sync, required account, or remote API for the core experience.
- **Inspectable:** starter source, prompt text, guides, and packaging scripts are visible.
- **Honest state:** illustrative prompts are identified as examples; workflow status comes from GitHub Actions rather than a hand-written success claim.
- **Useful without custom UI runtime:** the README uses native links, a small icon grid, tables, and expandable sections supported by GitHub.

<a id="quality"></a>
## 🔒 Quality, privacy, and trust

When available, the website stores small pieces of progress in the current browser's `localStorage`: theme, Kanban tasks, checklist and walkthrough progress, and the optional supporter name. Launchpad stores its goals locally as well. The site sends no data to a server and provides no sign-in, cloud sync, or analytics.

The prompts are written examples, not live AI responses. If you paste material into an external AI service, that service's privacy and retention rules apply. Do not paste passwords, private keys, access tokens, or confidential information into prompts.

The moon wallpapers are original artwork for this pack. The README hero visual is AI-assisted original artwork made for this repository. Review the terms of any third-party material before redistributing a modified copy. This repository does not currently declare a general open-source license for the complete source and artwork collection; do not assume every item is licensed for unrestricted reuse.

<a id="maintainers"></a>
<details>
<summary><strong>For maintainers: build and validate the source repository</strong></summary>

<br>

Building and testing the source archives requires **Node.js 18+, `zip`, and `unzip`**. From a repository clone:

```sh
npm run build   # regenerate deterministic ZIPs and docs/PROMPTS.md
npm test        # syntax, content, local-link, and archive checks
```

No `npm install` is required. The build writes the three tracked ZIP files; run the tests after rebuilding. The Quality workflow tests the existing downloads, rebuilds them, and tests the generated artifacts again. A green badge is only a snapshot of that workflow; inspect the run when making release decisions.

| Source path | Purpose |
| --- | --- |
| `index.html`, `styles.css`, `app.js` | Standalone website |
| `data/prompts.js` | Source for the 20 prompt cards |
| `freebie-creator-kit/` | Creator-kit source documents |

| `starter-project/` | Editable Launchpad source and walkthrough |
| `assets/` | Hero artwork, wallpapers, and navigation icons |

| `downloads/` | Recipient-facing ZIP artifacts |

The [testing and release checklist](docs/TESTING.md) describes automated checks and the manual browser pass. Automated checks do not prove universal compatibility with every browser, screen reader, operating system, or third-party licensing requirement.

## Repository integration: two independent browser experiences

- **[Luna's First Project Pack](index.html)** is the primary experience with seven local tools, 20 prompts, Launchpad, and the Creator Kit.
- **[Nexus Luna Toolkit Classic](classic/index.html)** preserves the former dashboard, quick launcher, local usage information, backup/import data center, and its own offline service worker.

To run both from a local server, use `python -m http.server 8080`. The Classic URL is <http://localhost:8080/classic/>. Their browser storage key prefixes are distinct.

The tracked ZIP downloads distribute the First Project Pack, **not** Classic. The source-only [repository scan](docs/REPO_SCAN.md) is intentionally excluded from public downloads.

The repository name reflects an earlier fan-project title and **does not imply affiliation** with the Global Partnership on Artificial Intelligence (GPAI), the OECD, or another organisation. This repository is not an official institutional presentation.
